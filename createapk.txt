==================================================
        HOW TO CREATE AN ANDROID APK (EAS BUILD)
==================================================

Step 1: Verify your Expo Login
--------------------------------------------------
Run this in your project terminal to check who is logged in:

  npx eas whoami

If you are not logged in, run:

  npx eas login


Step 2: Link Project (Only needed if changing Expo accounts)
--------------------------------------------------
If you change Expo accounts, link the project to your current account:

  npx eas init --account <your-username>


Step 3: Trigger the Android APK Build
--------------------------------------------------
Run the preview build command to generate a direct installable .apk file:

  npx eas build -p android --profile preview


Step 4: Download & Install
--------------------------------------------------
- Expo cloud servers will compile the app package.
- Once completed, the terminal will display a direct download URL and a QR Code.
- Scan the QR code with your phone camera or open the link to download and install the .apk file on any Android device!
